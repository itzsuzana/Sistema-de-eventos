# 🎟️ Sistema de Eventos

Sistema web desenvolvido para simular o controle de entrada de participantes em um evento.

O projeto começou como um exercício de verificação de idade e foi evoluindo para uma aplicação com formulário, validações, tipos de ingresso, horários e diferentes resultados de acesso.

---

## 🚀 Funcionalidades

-  Cadastro do nome do participante
-  Verificação da idade
-  Seleção do tipo de ingresso
-  Escolha do horário do evento
-  Liberação de entrada para maiores de 18 anos
-  Bloqueio de entrada para menores de 18 anos
-  Identificação de ingresso VIP
-  Exibição dos dados do participante
-  Validação dos campos obrigatórios
-  Botão para limpar o formulário
-  Interface adaptada para dispositivos menores
